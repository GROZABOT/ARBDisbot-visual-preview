# ARB DisBot — independent visual preview

This repository hosts 20 static, interactive visual mockups at GitHub Pages, before applying the approved design to the live service.

- UI navigation and demo controls work locally in the browser only.
- No Discord API, Stripe, GitHub Actions production deployments, backend requests, login, database operations, commands or credentials.
- Demo pricing and statistics come from approved visual examples, not live account data.
- The original approved pricing concept is preserved in assets/pricing-approved.png for comparison. The other page motifs are vector mockups of the approved visual direction and are subject to final user acceptance before production.
- Full-site background and neon style follow the reference pricing concept, with distinct imagery for each section.

**Source of truth for real commands, payments and policy remains the separate production repository.**
